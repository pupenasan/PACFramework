# Recommendations for Implementing PAC Framework on New PLC/PAC Platforms

## Implementation Sequence for new PAC Platform

- Implementation and testing of the simulation model:
  - [Model1: program for simulating an installation with dozators](SIMUL1/README_EN.md)
- Implementation and testing of PLC FN
- Implementation and testing of CH channels (LVL0)
- Implementation and testing of MODULES
- Implementation and testing of variables (LVL1)
