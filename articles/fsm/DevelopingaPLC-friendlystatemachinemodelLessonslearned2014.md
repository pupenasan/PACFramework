# Developing a PLC-friendly state machine model: Lessons learned

Pessemier, Wim & Deconinck, Geert & Raskin, Gert & Saey, Philippe & Winckel, Hans. (2014). Developing a PLC-friendly state machine model: Lessons learned. 9152. 10.1117/12.2054881. 

https://www.spiedigitallibrary.org/conference-proceedings-of-spie/9152/1/Developing-a-PLC-friendly-state-machine-model-lessons-learned/10.1117/12.2054881.full

Ця стаття — *"Developing a PLC-friendly state machine model: Lessons learned"* — присвячена створенню **моделі станів**, сумісної з **ПЛК (PLC)**, на основі **семантичного підходу** і **Semantic Web технологій**. Вона описує досвід авторів з KU Leuven, отриманий у процесі розробки інфраструктури керування астрономічними телескопами (зокрема Mercator), орієнтованої на сучасні стандарти IEC 61131-3 та OPC UA.

**Основні пункти статті:**

1. **Мета:** Побудувати "дружню до ПЛК" модель станів, яку можна використовувати в середовищі з OPC UA, Semantic Web, а також у платформах, заснованих на IEC 61131-3, з можливістю генерації коду.
2. **Семантичне моделювання:**
   - Розроблено онтологію `fsm`, яка формалізує поняття стану, переходу, умов, поведінки тощо.
   - Використано SPARQL, RDF(S), OWL і SPIN для визначення логіки поведінки систем.
   - Підхід дозволяє будувати як **платформо-незалежні** (PIM), так і **платформо-специфічні моделі** (PSM).
3. **DSL (domain-specific language):**
   - Створено спеціальні скрипти (на базі CoffeeScript) для опису моделей.
   - DSL дозволяє перетворювати семантичні моделі на код PLC та документацію.
4. **Генерація коду PLC:**
   - Використано IEC 61131-3 (SFC, ST, LD, CFC).
   - Пояснено шаблони програмування, що дають змогу поєднувати автоматично згенерований код з ручним.
5. **OPC UA:**
   - Використано OPC UA як основну архітектуру інтеграції.
   - Обговорено виклики у підтримці просунутих функцій OPC UA: методи, події, історичні дані тощо.
6. **Синхронізація в SOA:**
   - Обговорено проблеми, пов’язані з циклічним виконанням ПЛК-програм і доступом з декількох клієнтів.
   - Запропоновано рішення — методи OPC UA на основі сервіс-орієнтованої архітектури (наприклад, SOA PLC від Beckhoff).
7. **Висновок:**
   - Запропонована методологія дозволяє формалізовано створювати моделі станів і автоматично трансформувати їх у код для ПЛК.
   - Підхід ґрунтується на поєднанні семантичного моделювання, стандартів IEC 61131-3 та OPC UA для гнучкої і масштабованої архітектури керування.

Ця стаття буде особливо цікава для фахівців, які хочуть впроваджувати **модельно-орієнтовану розробку** (Model-Driven Engineering) у промислових системах автоматизації, де потрібна інтеграція ПЛК, OPC UA та "розумних" семантичних моделей.
