Стаття **"Generalized Symbolic Execution for Model Checking and Testing"** (Sarfraz Khurshid, Corina S. Păsăreanu, Willem Visser) присвячена новому підходу до автоматизованої перевірки правильності програм, особливо тих, які:

- працюють із **складними динамічними структурами даних** (списки, дерева);
- є **багатопоточними** (concurrent);
- приймають вхідні дані **з необмежених доменів**.

### Основні ідеї статті:

1. **Генералізація символьного виконання**:
   - Розширено традиційний підхід до *symbolic execution* (символьного виконання), що дозволяє:
     - працювати з динамічними структурами;
     - перевіряти перед- і післяумови;
     - підтримувати багатопоточність;
     - працювати з даними (цілі числа, рядки тощо).
2. **Інструментування коду**:
   - Програму автоматично модифікують (source-to-source трансляція), щоб її можна було перевіряти звичайним **модельним перевірювачем** (model checker) — зокрема, **Java PathFinder**.
3. **Алгоритм "лінивої ініціалізації"** (lazy initialization):
   - Під час символьного виконання об'єкти ініціалізуються тільки при першому доступі до них.
   - Це дозволяє уникати обмежень на розмір вхідних даних та генерувати **неізоморфні** тестові приклади.
4. **Застосування**:
   - **Перевірка багатопотокових програм**: приклад з помилковим розпаралеленим сортуванням елементів списку.
   - **Генерація тестів**: приклад із Altitude Switch (авіаційне ПЗ), де отримано повне покриття умов за 22 хвилини.
5. **Платформа реалізації**:
   - Java + Java PathFinder + Omega Library + Korat framework.
6. **Мета**:
   - Подолати проблему **state space explosion** у model checking.
   - Автоматизувати генерацію тестів для складних вхідних даних.
   - Перевіряти коректність без потреби вручну писати вхідні приклади.

------

Це фундаментальна робота в галузі верифікації програм, яка поєднує формальні методи (model checking), динамічний аналіз (symbolic execution) і практичні інструменти для реального програмного забезпечення.
